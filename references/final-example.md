# 示例与质量边界

完整合成示例：[输入](../examples/insight-input.md) → [洞见稿](../examples/insight.md)。它演示如何从中断与状态问题，递进到副作用、验证和能力评价；没有真实经历或实测成绩，不是所有文章的固定目录。

[短稿示例](examples.md)覆盖方案讨论、实践复盘、理论指标与资讯。不要把示例的事实、身份、措辞或目录搬进真实稿件。

质量验收应检查：中心判断、各节推进、证据角色、事实与权限保留、段落连贯，以及图文是否解释相邻论点。参见[语义评审](../evals/RUBRIC.md)。

本包不包含私人文档、知识库节点或作者本机路径。当前确定性测试覆盖结构与资产，示例用于教学；没有据此宣称跨主题、跨模型或平台发布效果已经得到统计验证。
